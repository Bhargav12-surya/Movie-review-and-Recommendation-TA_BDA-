# Provenance still required from the dataset owner

Local files and matching bundled checksums establish local consistency.
They do not authenticate the acquisition channel or create a usage permission.

For each supplied source, provide source_url, source_version, retrieved_at,
license_or_terms, permitted_use and any redistribution/retention restrictions.
Keep original README/license/checksum records. Mark unknown values as unknown;
do not substitute the audit timestamp for a download timestamp.

For first-party reviews add consent version, permitted research/training use,
withdrawal/deletion handling and a lawful pseudonymous reviewer reference where
needed. For annotated datasets record annotators, guideline/taxonomy version,
overlap agreement and adjudication.

The application does not call external providers to fill these fields.
Use the source records already supplied or the owner's documented acquisition
information. Leave unresolved rights/identity/consent as blocking conditions.
