# Final acceptance and submission checklist

Prepared 10 November 2026, Asia/Calcutta. All checkboxes initially remain open.
Generated source/documents and static checks do not close executed acceptance.
For every item retain an evidence ID/path/hash, source/model/data/config scope,
actual date/operator and reviewer. A skipped or unavailable required check is
not a pass. Record failures alongside successful runs.

## A. Before Phase12 execution

- [ ] Earlier phase gates and approved dependency-based exceptions are recorded;
  Phase1 permissions/mappings/annotations and final Phase2 runtime are accepted.
- [ ] Current explicit Python/JDK/Scala/Spark/Node/PostgreSQL/pgvector versions,
  package locks, native imports and required actual CUDA/precision checks match.
- [ ] Current available disk/RAM/VRAM supports the selected operating mode; no
  heavy Spark job or training competes with the full application demonstration.
- [ ] Raw sources remain unchanged and their local checksums/cards/terms exist.
- [ ] Genuine canonical IDs, review permissions, adjudicated labels, split/groups,
  duplicate/leakage checks and annotation supports are approved.
- [ ] Actual selected checkpoints/calibrators/tokenizers/reports and model cards
  are hash-bound; no binary IMDb neutral overlay is served.
- [ ] Reviewed score thresholds/prior/shrinkage/target policies, hybrid weights,
  candidate protocols and language scopes match their validation evidence.
- [ ] A disposable local PostgreSQL test database and separately reviewed demo DB
  exist; tests cannot target user-owned production/application data accidentally.
- [ ] Required software/models/metadata/artwork/browsers are already supplied
  manually; validation startup never installs or downloads missing resources.

## B. Phase12 correctness and real integration

- [ ] Actual unit/contract suites pass; skips, synthetic fixture boundaries and
  any model substitution used only in isolated tests are disclosed.
- [ ] Disposable PostgreSQL migration, pgvector/dimension and constraints pass;
  static ORM-column parity is not substituted for this check.
- [ ] Real authentication, token expiry/revocation behavior, admin protection,
  cross-owner rejection, idempotent replay/conflict and request bounds pass.
- [ ] Concurrent edits and in-flight analysis cannot overwrite a newer review;
  deletion/permission withdrawal removes current evidence and does not revive it.
- [ ] Worker lease/crash/restart/retry/queue-full/model-failure behavior is
  durable, bounded and free of fabricated predictions.
- [ ] Actual approved local sentiment/aspect/theme components load and persist
  their true outputs/version/coverage; unsupported inputs remain explicit.
- [ ] Eligible score/summary snapshots use current evidence/model/method versions;
  no-evidence movies display exactly "Not enough audience reviews yet."
- [ ] Target aspect/theme/genre reception uses valid target evidence; metadata,
  relevance, stars, public sentiment and personal matches remain distinct.
- [ ] Optional generated summary candidates stay withheld until matching factuality
  approval; evidence references and minority/contradiction coverage are reviewed.
- [ ] Real recommendations respect candidate/seen/eligibility/filter boundaries,
  consented profiles, separate app/source identities and actual explanations.
- [ ] Actual query examples, ambiguity, negation/runtime/genre intersection,
  follow-ups, context ownership/expiry/reset and evidence grounding pass.
- [ ] Real-service browser desktop/mobile/keyboard/loading/empty/error journeys
  pass; summary appears above reviews and no mock API response proves integration.
- [ ] Optional voice succeeds with permitted cached audio/model data, or its
  documented unavailable/microphone-denied path preserves usable text input;
  a fallback alone does not establish speech accuracy.
- [ ] Final Scala source compiles/runs; Parquet/RDD/DataFrame/Dataset/SQL outputs,
  counts/quarantine/joins/partition/DAG/cache evidence match the actual job.
- [ ] Stream new/replay/conflict/late/edit/delete/restart behavior and pending-
  revision lag are measured; final DB/Python/Scala/stream snapshots reconcile.
- [ ] Bounded actual p50/p95/error/throughput/queue/snapshot-lag/RAM/VRAM/load
  measurements satisfy the selected reviewed targets; no threshold is invented.
- [ ] The complete cached local journey is observed with the operator's recorded
  no-network method; flags alone are not proof of offline operation.
- [ ] Relevant failures and recovery paths are rehearsed without deleting raw
  data, resetting Git, killing unrelated processes or installing rescue packages.

## C. Phase13 scientific and submission evidence

- [ ] Report questions/methods/splits/selection/calibration are fixed and actual
  results support every conclusion; final-test access was not reused for tuning.
- [ ] LR/SVM/Transformer comparisons share a task/split; binary and three-class
  tables are separate and report per-class supports/confusion/calibration.
- [ ] Informal/language/sarcasm cohorts and explicit/full aspect pipelines have
  genuine support/results, or unavailable limitations are stated.
- [ ] Theme/topic/retrieval/summary/risk results state exactly what was measured;
  no fake accuracy, overlap-as-truth or universal multilingual claim appears.
- [ ] Ranking results disclose temporal splits, K, sampled/full candidates,
  train-only novelty/popularity, diversity definitions and cold/empty supports.
- [ ] Every published table cell/claim resolves to an actual report field and
  correct source/data/model/protocol hashes; missing metrics stay unavailable.
- [ ] Architecture/ER/API descriptions match current source and actual migrations.
- [ ] BDA/TA syllabus claims link inspected source and executed evidence; missing
  POS/NER/HMM/CRF/Graph/translation exercises are not claimed implemented.
- [ ] Model/dataset cards list real provenance, licenses, actual results, intended
  scope, exclusions, resource limits and known errors.
- [ ] The report, tables, model cards and presentation agree with saved evidence.
- [ ] Required data/model/software/artwork rights, notices and attribution are
  reviewed for the exact selected shareable artifacts.
- [ ] Private reviews/audio/consent/credentials/raw datasets/restricted assets are
  excluded from the default shareable bundle and screenshots/logs reviewed.
- [ ] Curated source/lock/config/report manifests are frozen in a new versioned
  directory, hashes verified and the user's working-tree changes preserved.
- [ ] A fresh-terminal setup and measured coherent demo/recovery script have
  been rehearsed on the laptop; no model retraining is needed during evaluation.

decision must distinguish a source handoff, a reproducible executed system and
an academically justified conclusion.
